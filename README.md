# TweenAvalonia

![NuGet](https://shieldcn.dev/badge/NuGet-0.3.1-004880.png?variant=outline&logo=nuget)
![CI](https://shieldcn.dev/github/SBUplakankus/tween-avalonia/ci.png?variant=outline&logo=githubactions)
![License](https://shieldcn.dev/github/SBUplakankus/tween-avalonia/license.png?variant=outline&logo=gnu)

Programmatic tweens for Avalonia. Avalonia's XAML `Transitions` are fire-and-forget: you can't stop them, complete them, or get a completion callback. TweenAvalonia gives you a handle to every animation you start. Only the target and end value are required.
